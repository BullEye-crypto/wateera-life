# Wateera Life | وتيرة

Wateera Life is an early-stage educational platform for computer science and artificial intelligence students, with a focus on accessible learning in Arabic and English.

## Project goals

- Make technical concepts easier to understand through bilingual explanations.
- Support interactive lessons, practice questions, and immediate feedback.
- Provide mobile-friendly study resources for university students.
- Develop reusable educational tools that can be improved by the open-source community.

## Repository status

This repository is being prepared for the initial open-source release. The hosted platform and this public repository are not yet equivalent: the application source has not been published here.

## Roadmap

- Publish reusable lesson and assessment components.
- Document the lesson data format and local development setup.
- Add tests for assessment behavior and accessibility.
- Provide contribution guidelines and sample learning content with appropriate licensing.

## Contributing

Ideas, bug reports, and accessibility suggestions are welcome through GitHub Issues. Please do not include personal student data, credentials, or copyrighted course materials in contributions.
